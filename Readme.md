# SDR
## Общая информация и инструкция по установке

### Папка reports
- В этой папке лежит Readme для отчетов
- В папках reports/week... лежат скриншоты для отчетов

### Папка libs
- Тут лежат сабмодули на используемые библиотеки

### Инструкция по установке и компиляции
- Склонируйте репозиторий с флагом "--recursive" git clone --recursive https://github.com/tortikmam/SDR.git
- Проверьте что указан правильный ip адрес AdamPluto
- Запустите файл run.sh для компиляции 
- Перейдиет в папку build, запустите исполняемый файл и укажите что нужно использовать (приемник или передатчик)
- Например: "./main tx" или "./main rx"
